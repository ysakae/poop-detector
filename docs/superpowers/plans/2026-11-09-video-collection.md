# 動画収集とラベル付けの実装計画

目的：排泄前後の短時間動画を保存し、便・尿・非排泄動作と時刻を人手で付けられるようにする。
構成：clips.pyにSQLiteメタデータ・容量上限・リングバッファとFFmpeg処理、clip_gui.pyに表示・HTTP配信・ラベル検証を分離する。

1. tests/test_clips.pyにバッファ範囲、複数要求、容量、部分クリップ、実MP4変換の失敗するテストを作る。
2. clips.pyを実装し、LatestCameraのフレームコールバックとmonitorの検知・要求処理へ接続する。
3. tests/test_clip_gui.pyに動画配信Range・ラベル時刻範囲・手動保存要求・パス制限のテストを作る。
4. clip_gui.pyと既存GUIを接続し、動画内秒数で開始/完了を記録する。
5. 全pytest、ruff、FFmpegのデコード、ブラウザでの再生UIを検証し、コードレビューで残件を確認する。

重点：切断時の時間飛び、メモリー無制限増加、GUIと監視の別プロセス、カメラ不在での保存要求、保存途中ファイルの公開を防ぐ。
姿勢モデルの学習は十分な実動画・ラベルが蓄積してから次段階で行う。
