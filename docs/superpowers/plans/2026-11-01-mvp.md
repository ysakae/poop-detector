# 排便の疑い検知MVPの実装計画

添付の開発指示を仕様とし、Python 3.11以上・uv・OpenCV・SQLiteで実装する。
画像差分ではSUSPECTEDまでとし、排便の確定や姿勢予測は実装しない。

1. 人工画像で、空状態・小物体・犬相当の大きい遮蔽・照明変動をテストする。
2. 正規化ROIの保存と解像度変更、状態管理の継続確認と重複抑制をテストする。
3. SQLiteへのイベント記録、フィードバック、見逃しラベル、指標集計をテストする。
4. カメラ読込のタイムアウト・切断・再接続と通知をテストする。
5. 各テストの失敗後に対応モジュールを実装する。
6. CLIで接続確認、ROI選択、基準登録、監視、確認、フィードバック、評価を接続する。
7. pytestとruff、人工映像の統合実行で検証し、実機未確認項目をREADMEに明示する。

担当モジュール：camera.py（取得）、roi.py（領域）、detection.py（差分）、
state_machine.py（継続確認）、events.py（記録と評価）、notifications.py（通知）、
config.py（設定検証）、main.py（CLI）。

重点確認：接続切断で継続時間を引き継がない。遮蔽中に通知しない。
解像度変更で基準を誤適用しない。認証URLをログに出さない。
未ラベルデータから精度を断言しない。基準再登録は明示的な操作に限定する。
