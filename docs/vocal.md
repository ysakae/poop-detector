# 鳴き声の記録（実験的）

カメラの音声から、犬が鳴いたり吠えたりしていた時間を記録します。分離不安の度合いや、留守中に何かに驚いていないかを知る手がかりにします。

## 使う前に確かめる

カメラの RTSP が音声を流しているかを確かめます。

```bash
uv run poop-detector check-camera --audio
```

「音声: あり（aac）」のように出れば使えます。「音声: 見つかりません」のときは、カメラのアプリで音声（マイク）が有効か確かめてください。

## 有効にする

```bash
uv run poop-detector run --audio
```

設定ファイルでは `features.audio: true` です。犬の検出は使いません。

## 数え方

- 映像とは別に FFmpeg で音声だけを読み、0.5秒ごとに音量と、鳴き声の帯域（300〜4000Hz）の割合を測ります。
- 周りの静かなときの音量より `audio.threshold_db`（既定15dB）大きく、鳴き声の帯域が多い音を鳴き声の候補にします。冷蔵庫や換気扇のような低い音は数えません。
- 3秒までの切れ目はつないで1回とし、鳴いていた時間が1秒に満たない物音は記録しません。
- 起動してから5秒は周りの音量を覚えるので、数えません。

## 見る

記録の画面の下の「鳴き声の記録」（`/vocal`）に、直近14日の日ごとの回数と鳴いていた時間、最近の鳴き声を出します。留守中のまとめの年表にも並びます。

## 知らせる

ホームで「外出中にする」を押している間に、10分のうち合計 `audio.notify_seconds`（既定60秒）鳴いていたら知らせます。続けて知らせるのは30分あけてからです。在宅中は記録だけにします。

## 鳴き声のモデルで確かめる（試作）

音量と帯域だけでは生活音も数えるので、見つけた区間の音を、手元で動く音声分類のモデル YAMNet（Google、AudioSet の521クラス）にかけて「犬らしさ」を記録できます。記録する区間は減らさず、犬らしさを並べて残すだけです（採否は、下の評価で決めます）。

```bash
uv sync --extra audio-model
uv run poop-detector setup-vocal-model
```

1つ目で実行の部品（LiteRT の `ai-edge-litert`）を入れ、2つ目で Google の MediaPipe が配るモデル（約4MB）と、tensorflow/models のクラスの一覧を、固定の場所から SHA-256 を確かめて `data/models/yamnet/` に取得します。そのうえで設定の `audio.model: true` にして監視を起動し直すと、区間ごとに犬らしさ（犬・吠え声・遠吠えなどのクラスの確からしさの最大値）と、いちばん近いクラス（Speech・Television など）が記録されます。

## 評価用に短い音を残す

`audio.keep_days`（既定 0）を 1 以上にすると、区間の音（最長10秒）を `data/vocal-clips/` に WAV で残し、その日数で消します。バックアップには入れません。家族の同意のうえで、期間を決めて使ってください。

「鳴き声の記録」の画面で、残した音を再生して「鳴き声」「ほかの音」のラベルを付けると、ラベルを付けた区間で、今の判断（鳴き声と数えたうち本当に鳴き声だった割合）と、モデル（犬らしさ 0.5 以上を鳴き声とした場合の当たり具合と見つけられた割合）を比べたまとめが出ます。

## プライバシーと制限

- 音声そのものは、`audio.keep_days` を 1 以上にしたときだけ評価用に残し、その日数で消します。それ以外に記録するのは、鳴いていた時刻・長さ・最も大きな音量（dBFS）と、モデルを使うときの犬らしさといちばん近いクラスの名前だけです。保存した動画にも音声は入りません。
- テレビ・掃除機・インターホン・人の声とは区別できないことがあります。実際の音での精度は確かめていません。
- 鳴き声らしさを手元のモデル（YAMNet）で確かめる案と評価の進め方は、[鳴き声らしさを分類するモデルの調査](vocal-model-survey.md)にあります。
