記録の書き出し

確定した排泄の記録（日時・種類・場所・メモ）を、開始の日付で期間を選んで書き出します。時刻はこのマシンのタイムゾーン（{{ timezone }}）で、時差を付けて書きます。

{{ csrf_field(token) }}

CSV は Excel などでそのまま開ける UTF-8（BOM 付き）です。印刷用の集計は、期間の回数と時間帯の分布を1ページにまとめます。ブラウザーの印刷で紙や PDF にしてください。

バックアップ

記録のデータベース、監視範囲・基準画像などの登録情報、検知の画像を1つの ZIP にまとめます。監視の動作中でも作れます。

{{ csrf_field(token) }}

ログインのセッション、登録用 URL、Web Push の購読と秘密鍵、.env、設定ファイル、犬検出モデルは含めません。ユーザーとパスキーは含めるので、復元した後も同じパスキーでログインできます（通知の購読はやり直してください）。家の中の画像を含むので、ファイルの置き場所に気を付けてください。

復元

復元はデータの保存先を入れ替えるので、画面からは行いません。監視と GUI を止めてから、監視するマシンで次を実行してください。

uv run poop-detector restore バックアップのファイル.zip

中身を確かめて確認を求めてから入れ替えます。元のデータは消さず、data.before-restore-日時 のように名前を変えて残します。
